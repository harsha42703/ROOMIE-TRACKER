# 🏠 ROOMIE TRACKER

ROOMIE TRACKER is a premium roommate expense management web application designed to help friends, roommates, and teams easily track shared expenses, split bills, and manage balances in a beautiful modern UI.

Built with **React, Tailwind CSS, Zustand, and Recharts**, this app provides a smooth mobile-first experience and works like a Progressive Web App (PWA).

---

## ✨ Key Features

### 👥 Multiple Expense Sheets
- Create unlimited groups (sheets)
- Each sheet stores its own members and expenses
- Easily switch between sheets

---

### 💸 Smart Expense Splitting
- Split bills among selected members
- Add new members instantly while splitting
- Automatic equal distribution of amounts

---

### 📊 Balance Tracking
- Real-time balance calculation
- Shows who owes money and who will receive
- Settlement suggestions for clearing debts

---

### 📈 Analytics Dashboard
- Per-person pie charts
- Balance visualization
- Monthly expense tracking

---

### 📄 Reports & Sharing
- Generate PDF reports
- Share expense summaries
- WhatsApp reminder links

---

### ⏰ Monthly Reminder System
- Due date automatically set to 1st of each month
- Reminder period from 1st to 3rd
- Red/Green balance indicators

---

### 🎨 Premium UI/UX
- Glassmorphism theme
- AMOLED dark mode
- Multi-color theme switcher
- Rounded bottom navigation
- Fully mobile responsive

---

### 📱 PWA Ready
- Installable on mobile home screen
- Works offline
- Fast loading experience

---

## 🛠️ Tech Stack

- React (Vite)
- Tailwind CSS
- Zustand (State Management)
- Recharts (Charts)
- html2canvas + jsPDF (Reports)
- LocalStorage Persistence
